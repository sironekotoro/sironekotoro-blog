# 移行試作メモ

- 過去本文はHTMLとして保持し、変換時に `script` と危険な属性を除去する。
- YouTubeとはてなブログカードのHTTPS iframeはsandbox付きで許可する。それ以外のiframeは除去される。
- Twitter/Xは引用HTMLを残し、外部widgets scriptを実行しないため静的表示になる。
- GitHub GistのscriptはGistへの通常リンクへ置換する。
- 内部リンクは `sironekotoro.hateblo.jp/entry/...` を同じローカルパスへ置換する。
- Fotolife画像だけを代表記事の範囲で取得可能。外部サービス画像は元URLを保持する。
- 全件移行前に、除去された埋め込みの個別確認、画像利用条件、旧URLのクエリ/アンカー、HTMLの崩れ、リンク切れを全記事で監査する。
- 原本はUTF-8として妥当だが、既存のUnicode置換文字を含む。本文をログへ出さず件数だけを集計し、該当公開記事は全件移行前に目視確認する。
- ローカル表示では、はてなブログカードのiframeが空枠になる例があった。全件移行前にURLを抽出して通常リンクカードへ変換する方式を追加検討する。
